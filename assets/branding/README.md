# Platform branding

The source artwork is the Figma cat-and-heart app icon (`200:23599`), also used by `assets/icons/app-logo.svg`. `app-icon.png` is the 1024px transparent rounded tile; `foreground.png` contains the original cat artwork without its background. Both were rasterized with Flutter's SVG renderer using the application header's sRGB brand colors.

Regenerate platform assets from the project root:

```sh
sh tool/generate_branding.sh
```

The command runs the development dependencies `icons_launcher` and `flutter_native_splash` with their root YAML configurations. It requires Flutter/Dart and Git, not Python/Pillow. The packages own raster resizing, density variants, icon catalogs and splash markup. Generated assets are checked in; no runtime splash dependency, timer, preserve/remove call or delayed first frame is introduced. Web dismisses the generated splash on the existing `flutter-first-frame` event.

Source artwork variants preserve the previous geometry:

- `icon-square.png`: opaque gradient and original foreground for iOS.
- `icon-maskable.png`: full-bleed gradient and 80% foreground for web maskable icons.
- `icon-macos.png`: original tile at 80% size with transparent outer clearance.
- `adaptive-foreground.png`: foreground at 72% size in Android's 108dp adaptive layer; `adaptive-background.png` is the full-bleed Brand 400 (`#FFBC00`) to Brand 600 (`#E87000`) gradient.
- `splash.png`: 384px original tile, interpreted as 4x artwork to retain a centered 96 logical-pixel splash on Android, iOS and web.

These are checked-in source variants, not a second resizing pipeline. Package resampling can differ slightly from the former Pillow output. The favicon is now 48px; Windows ICO also includes 96px. Artwork, margins and colors remain the same.

`info_plist_files: []` prevents the splash package from editing Info.plist. The wrapper preserves existing Android styles (including Android 12 light/dark files) and removes generated styles only where no file existed before the run, including on generator failure. `platform-preservation.patch` restores native system backgrounds, removes the generator's restrictive web viewport tag and retains the accessible loading label. Unused generated background bitmaps and the iOS LaunchBackground asset catalog are removed after the patch replaces their references. Android 12 keeps its existing configuration (currently the OS-default launcher splash). On package upgrades, review this patch against generated output; failures stop regeneration rather than silently accepting changed appearance or metadata.

Linux generation is disabled because `icons_launcher` creates Snapcraft packaging rather than this application's existing desktop bundle. The existing 256px Linux icon and 180px web Apple touch icon remain checked-in assets; neither is generated by this command. Replace those exports too if the source artwork changes. Linux bundles retain the desktop entry and hicolor icon under `share/`, with the window icon in `data/`.

Visible names remain **Cat tinder** and the description remains **Discover cat photographs and explore their breeds.** Bundle/application identifiers and executable names are unchanged. Final release identity, signing and platform acceptance remain delivery decisions.
